# CS-312 Mini-Project 1
This is my first mini-project. I created a basic blog web application using Node.js, Express.js, and EJS.
Users can just create, view, edit and delete their posts.
## Project features
- Create new blog posts
- View all blog posts
- Edit existing posts
- Delete posts
- Responsive design for desktop and mobile screens
## Technologies I used
- Node.js
- Express.js
- EJS
- HTML
- CSS
## Steps to follow
1. Install the project dependencies:
   npm install
2. Start the server:
   npm start
3. Open http://localhost:3000 in a web browser.
## Notes
For this project I used an array instead of a database, so all posts disappear when the server restarts.
